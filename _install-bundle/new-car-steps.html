ขั้น 1 ปลดล็อก ADB ด้วย USB ที่รถ

USB (ราก) └── 3C6025_SW0E22H0306H111400000_user_995 └── OS └── update.zip ← ห้ามแตกไฟล์
  1. เสียบ USB รอจอขึ้นว่าเจอ USB
  2. ปิด Bluetoothไม่งั้นแอพโทรศัพท์จะโทรออกจริง
  3. เปิดแอพโทรศัพท์ → กดรหัส Engineering Mode
  4. กดไอคอนติดตั้งอัปเดต ตัวเครื่องหมายสีเขียวจอรีบูตเข้า Recovery แล้วรันเอง ไม่ต้องกดอะไร
  5. จบแล้ว ขึ้น error = ปกติ → กดค้าง Previous Track บนพวงมาลัย จนจอรีสตาร์ต
  6. ADB เปิดแล้ว → ถอด USB

ขั้น 2 ต่อ Wi-Fi + เปิดปุ่ม ADB

  1. Engineering Mode → รายการ สีน้ำเงิน → ตั้งค่า Wi-Fiต่อ hotspot / Wi-Fi วงเดียวกับคอม
  2. จด IP ที่คอลัมน์ซ้าย → ใส่ในช่อง IP ด้านบนหน้านี้
  3. แอพโทรศัพท์ → รหัส Dialer Mode → กดปุ่ม ADB 1 ครั้ง

ขั้น 3 ลงระบบจากคอม พิมพ์ในแชท Claude Code

    ! bash "C:/Users/Pishe/Desktop/geely-ex2-notes/_install-bundle/new-car-system.sh" {IP}
  2. จอบูตเสร็จ → ต่อ Wi-Fi + กดปุ่ม ADB ใหม่
  3. ลง SmartTube + เปิด Wi-Fi 
    ! powershell -File "C:\Users\Pishe\Desktop\geely-ex2-notes\_install-bundle\install.ps1" -Only smarttube -Ip {IP}
  4. ทดสอบ ปิดจอ / เกียร์ R / ความสว่างจอดรถ เกียร์ P · ทำตามที่สคริปต์บอก (กด 🌚, เข้า R, แตะปลุก) 
    ! bash "C:/Users/Pishe/Desktop/geely-ex2-notes/_install-bundle/test-screen-off.sh" {IP}
  5. ลง Google Play → จอรีบูต (แล้วกดปุ่ม ADB ใหม่) 
    ! bash "C:/Users/Pishe/Desktop/geely-ex2-notes/_install-bundle/gapps/install-gapps.sh" {IP}
  6. เปิด Play Store → login → ติดตั้ง YouTubeบูตแรกช้า 1–3 นาที · รอ Play Store อัปเดต Play Services เองก่อน

ถ้าเจอ "อุปกรณ์ไม่ได้รับการรับรอง"

  1. เปิด Play Store + ต่อเน็ต 1–2 นาที
  2. ดึงเลข GSF ID 
    ! bash "C:/Users/Pishe/Desktop/geely-ex2-notes/_install-bundle/gapps/get-gsf-id.sh" {IP}
  3. เปิด google.com/android/uncertified → ล็อกอินบัญชีเดียวกับในรถ → ใส่เลข → Registerรอ ~30 นาที
  4. ล้างข้อมูล Play Store + Play Services → login ใหม่

เช็กที่รถ ลองให้ครบ

  1. กด 🌚 ปิดจอ → ทั้งจอรวมแถบเมนูล่างมืดเท่ากันหมด
  2. ตอนจอดับ แตะกลางจอ / แถบบน / แถบเมนู → ติดทุกครั้ง
  3. ตอนจอดับ เข้าเกียร์ R → จอติดเอง เห็นกล้องถอย
  4. เปิดประตู → กระจกค่อยๆ ลง · ปิดประตูกลางทาง → หยุดแล้วปิดกระจก
  5. ดับรถ → รอ → สตาร์ทใหม่ → Wi-Fi ต่อเองภายใน ~30 วิ
