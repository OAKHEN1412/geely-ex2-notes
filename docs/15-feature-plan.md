# 15 — แผนฟีเจอร์ที่ยังขาด (เทียบคู่แข่ง "แผนก IT EX2") · 30 ก.ย. 2026

ที่มา: คำบรรยาย 18 โพสต์ + ภาพโพสต์ปักหมุดของ TikTok @it.ev.unlockservice
คู่แข่งใช้แอป "กบซิ่ง" = **EX Sapo Central (CentralEXAuto)** แปลไทย + ลงแอปเพิ่ม (วิเคราะห์ไว้ใน `_CentralEXAuto/_analysis/`)

## หลักการ
- ใช้ VHAL ผ่าน `CarPropertyManager` (เราเป็น uid system อยู่แล้ว) — **ไม่ใช้** ช่องทาง adb ภายในเครื่อง / bind-mount แพตช์แอประบบแบบ CentralEXAuto
- ทุกฟีเจอร์ที่ต้องใช้ค่าจากรถ: เขียนโค้ด + ทดสอบ UI บนเครื่องจำลองได้ แต่ **ค่าจริงต้องยืนยันบนรถ** ก่อนเปิดเป็นค่าเริ่มต้น
