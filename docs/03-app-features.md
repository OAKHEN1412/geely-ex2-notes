# 03 — ฟีเจอร์: สองฝั่งทำอะไรได้บ้าง

## สั่งงานได้จากมือถือ (ผ่าน VHAL ของรถ)

หน้าจอในแอปมือถือ (SwiftUI/Compose): **Tổng quan · Điều khiển · Điều hoà · Lái xe · Cài đặt**

- **ภาพรวม (Tổng quan)**: แบต %, ระยะวิ่ง (Còn đi được), ลมยาง (Áp suất lốp), อุณหภูมินอกรถ, ความเร็ว, แจ้งเตือนประตูไม่ล็อก/กระจกเปิด
- **ควบคุม (Điều khiển)**: ล็อก/ปลดล็อกประตู, กระจก (ลากขึ้น-ลง, Mở hết/Đóng), ฉากสำเร็จรูป (Chế độ nhanh/thư giãn/Nghỉ ngơi/Cắm trại), ไฟ ambient, เลือกสีธีมตามสีรถ
- **ปรับอากาศ (Điều hoà)**: อุณหภูมิ, พัดลม (Mức quạt: Thấp/Trung bình/Cao), A/C, ECO, ทำเย็น/อุ่นเร็ว, หมุนเวียนอากาศ (Gió trong/ngoài), ไล่ฝ้า (sấy kính), ฮีตเตอร์เบาะคนขับ
- **การขับขี่ (Lái xe)**: โหมดขับ, regen (Thu hồi năng lượng), เสียง AVAS
- **ตั้งค่า (Cài đặt)**: สแกน BLE / กรอก IP WiFi, ธีมสี, เวอร์ชัน 1.0.0, ติดต่อ Zalo

## ฝั่งรถทำเองได้ ไม่ต้องมีมือถือ

`Geely-Ex2-Car.apk` ไม่ใช่แค่ตัวรับคำสั่ง — มีฟีเจอร์อิสระของตัวเอง (ทุกอันมี `RestoreService` = รีบูตแล้วค่ายังอยู่):

| ฟีเจอร์ | คลาส | ทำอะไร |
|---------|------|--------|
| ปิดกระจกอัตโนมัติ | `AutoWindowController` | สั่งปิดกระจกตามความเร็ว (`AUTO_WINDOW_MAX_SPEED_KMH`, `AUTO_WINDOW_CLOSE_MAX_PERCENT`, `AUTO_WINDOW_DROP_PERCENT`) |
| คุมเสียง AVAS | `AvasController` + `AvasMuteApplier` | ปรับ/ปิดเสียงเตือนคนเดินถนนของรถ EV (`AVAS_VOLUME_MIN/MAX/STEP`) |
| ตั้งเวลาไฟ ambient | `AmbientLightScheduleController` | เปลี่ยนสี/โหมดตามช่วงเวลาผ่าน alarm |
| ไอคอนบนแถบสถานะจอ | `statuswidget` (`FLAG_STATUS_ICON_*`) | เพิ่มแบต/ความเร็ว/อุณหภูมินอกรถ/Wi-Fi ขึ้นแถบสถานะ |
| เปิด Wi-Fi อัตโนมัติ | `WifiAutoEnableController` | สะดวกตอนจะต่อ ADB รอบถัดไป |
| โหมดแคมป์ปิ้ง | `ACTION_START_CAMPING` | — |

> **ข้อสังเกต**: ฟีเจอร์กลุ่มนี้ (ปิดเสียง AVAS, ปิดกระจกอัตโนมัติ, ไอคอนแถบสถานะ) ใช้ได้โดย **ไม่ต้องมีมือถือ** — ถ้าเป้าหมายคือแค่พวกนี้ ปลดล็อก + ลง Car.apk ตัวเดียวจบ

## Safety interlock (คนทำคิดมาแล้ว)

โค้ดบล็อกคำสั่งอันตรายตอนรถวิ่ง (ข้อความเวียดนามในโค้ดจริง):

- `km/h) — chặn điều khiển cửa/kính khi lái` — บล็อกสั่งประตู/กระจกตอนขับ
- `xe đang chạy (` — รถกำลังวิ่ง → ปฏิเสธคำสั่ง
- `không xác định được trạng thái đỗ (gear/tốc độ) — chặn để an toàn` — อ่านเกียร์/ความเร็วไม่ได้ = บล็อกไว้ก่อน

## ภาษา

- แอปมือถือ (iOS + Android): **เวียดนามล้วน** hardcode ในโค้ด — ไม่มี `.lproj` / `values-xx` / สลับภาษาไม่ได้
- `Geely-Ex2-Car.apk`: มี `AppLocale` enum = **VIETNAMESE / ENGLISH** สลับได้ในหน้า Settings
- **ไม่มีภาษาไทย ไม่มีภาษาจีน** เลยสักไฟล์
- ผู้พัฒนา: งานชุมชนคนเวียดนาม ติดต่อผ่าน Zalo (ในแอปเขียนชื่อ "Saturn Lai")
- ไอคอนแอป: รูป Geely EX2 สีขาวบนพื้นดำ
