## 1. ปลดล็อก ADB ด้วย USB
- ใช้ได้ผลเมื่อ: **zip ต้นฉบับ (ตรง Google Drive ทุกไบต์) แตกทั้งก้อนไม่แก้อะไร** ลง USB ที่ฟอร์แมตใหม่ทั้งแท่ง (fat32format, MBR, FAT32 เต็มแท่ง)
- ไม่ได้ผล: USB เดิม (พาร์ทิชัน 32GB บนแท่ง 64GB อดีต ESD-USB) แม้โฟลเดอร์ถูก · วาง `sbdUpgrade\OS\`, `JsbdUpgrade\OS\`, ราก, `OS\` — ขึ้น toast `ensure udisk plugged and update.zip exists under udisk \sbdUpgrade\OS directory` ทั้งหมด
- **ยืนยันแล้ว**: toast บอก path ผิด (วางตามนั้นก็ไม่ได้) · ต้องมีโฟลเดอร์ `3C6025_<SW>_user_995\OS\update.zip` · update.zip ของ 1111/1114 เหมือนกันทุกไบต์ ต่างแค่ชื่อโฟลเดอร์ · สคริปต์ในแพตช์เช็กแค่ `ro.product.device==IHU629G` แล้วเขียน `persist.adb.tcp.port=5555`
- **สมมติฐาน**: A–C ล้มเพราะสภาพ USB/mount เดิม (เปลี่ยนหลายตัวแปรพร้อมกัน สรุปแน่ไม่ได้)
- **รีเซ็ตโรงงาน = ล้าง /data** → ค่า adb tcp หาย → ต้องรันแพตช์ USB ใหม่ · ไฟล์ใน /system (แอพ EX2, ex2_backlight.rc) ยังอยู่
- หลังรันแพตช์ใหม่ ADB ต่อได้เองหลังรีบูต ไม่ต้องกดปุ่มใน Dialer

## 4. ฟีเจอร์ใหม่ในแอพ EX2
- **ปุ่มปิดจอ** (ตรวจกับซอร์ส AOSP 9): overlay `TYPE_SYSTEM_ERROR` (layer 26 เหนือ status 17/nav 23) + `WATCH_OUTSIDE_TOUCH` + `KEEP_SCREEN_ON` · ปลุกที่ ACTION_DOWN · addView ก่อนดับไฟ · crash guard คืนแสง · ทดสอบบนเครื่องจำลอง: แตะแถบบน/ล่าง/กลางจอติดทุกจุด, เกิน timeout ไม่หลับ
- **เกียร์ R ตอนจอดับ = เปิดจอ** (`ReverseWatch`: GEAR_SELECTION/CURRENT_GEAR, R=2 ยืนยันจาก CentralEXAuto)
- **กระจกค่อย ๆ ลง** (`WindowStepper` + smali hook) · แก้ race: ล็อกร่วมกับคำสั่งปิด (ไม่ให้สเต็ปมาหลังปิดประตู)
- **Wi-Fi เปิดเสมอ** (`WifiKeeper`): เปิดตอนบูต/ตื่น, ไม่แตะเมื่อ hotspot/เครื่องบิน/จอหลับ, **เจอวงที่เคยต่อ = สั่งต่อทันที** · บนรถ: ตื่นจาก sleep ต่อ "oak" เองใน ~5 วิ
- **GmsGuard**: GMS 26.x เปิด `PhoneHubService` คืนเองเป็นรอบ ~3 นาที → PhoneHubChimeraService crash (CrossProfileApps null) · เฝ้าปิดตอนบูต/PACKAGE_CHANGED/ทุก 5 นาที (PACKAGE_CHANGED มาช้า ~10 วิ → ยังมี crash ระลอกเล็ก ถ้าไม่มีบริการจำลอง)

## 5. แบ่งจอ 2–3 แอพ (freeform)
- ตั้งค่า Global 3 ตัว (`development_settings_enabled`, `enable_freeform_support`, `force_resizable_activities`) + รีบูต 1 ครั้ง
- เปิดจาก: ไอคอน "แบ่งจอ" · กล่องลอย ☰ → 🪟 แบ่งจอ / ▶ แบ่งจอล่าสุด
- ส่วนประกอบ: `SplitActivity` (เลือกแอพ, โหลดรายชื่อเบื้องหลัง) · `SplitScreen` (วาง/ย้าย task, worker thread) · `SplitBackdropActivity` (พื้นดำ) · `SplitBackButtons` (◀ ต่อหน้าต่าง: setFocusedTask + inject BACK) · `SplitDividers` (ลาก=ปรับขนาด, แตะ ⇄=สลับ)
- ปัญหาที่เจอ+แก้ (วัดจริง):
  - แอพที่ 2 ไปโผล่ stack fullscreen → ย้ำกรอบ (enforce)
  - สั่งบน main thread = เฟรม 650ms → ย้ายไป worker (เหลือ 300ms)
  - **หน้าต่างกระโดด** (อัดวิดีโอเครื่องจำลอง): `setTaskWindowingMode` วางกลางจอก่อน resize + enforce ซ้ำ · ยืนยัน: `resizeTask` บน task เต็มจอ = "not allowed", start ซ้ำพร้อม freeform ไม่ย้าย task → แก้: ทำเท่าที่จำเป็น + ปิดแอนิเมชันชั่วคราว (คืนค่าเอง/คืนตอน DevService เริ่ม) · แอพเดิมไม่ถูก force-stop (pid เดิม)
  - **สลับแล้วหน้าต่างหาย/กินขอบ**: Android 9 stack freeform ไม่อยู่บน fullscreen เสมอ → `moveTaskToFront` ทุก task หลังจัด/สลับ · บนรถ: Maps↔YouTube สลับถูก ทั้งคู่ visible
- บั๊กค้าง: กดปุ่ม "ขยายเต็มจอ" บนแถบหน้าต่างตอน task ไม่อยู่ freeform แล้ว → Maps crash `exitFreeformMode: You can only go fullscreen from freeform` (ปุ่มของระบบ)

## 6. บริการระบบจำลอง (`devkit/stub/StubServices.java`)
- จอ ROM ตัด `crossprofileapps`, `batteryproperties`, `battery` ทิ้ง (ยืนยัน `service check`) · ไม่มี healthd
- ผลกระทบ: GMS PhoneHub crash วน · Google Maps crash ตอนเปิด (BatteryManager null)
- stub (app_process ในสิทธิ์ root ผ่าน adb) ลงทะเบียน 2 บริการได้ (SELinux Enforcing แต่ไม่บล็อก) · บนรถ: เปิด PhoneHub คืนแล้ว 0 crash ใน 45 วิ, **Maps เปิดได้**
- CAPACITY = prop `sys.ex2.soc` (ค่าเริ่ม 100)
- **ไม่ถาวร**: หายเมื่อจอรีบูต (ดับ/สตาร์ทรถ = sleep ไม่หาย) · การฝังช่องทางสั่ง root ในแอพเพื่อให้ถาวร **ไม่ทำ** (ความเสี่ยงด้านความปลอดภัย) → เปิดใหม่ด้วยมือจากคอมหลังรีบูต

## 7. ตำแหน่ง/Google Maps
- GPS เดิมไม่ติด: สัญญาณอ่อน (Top-4 CN0 18.6 dB-Hz) ในอาคาร · ชิปแจ้ง `FIX_READY, GET_RTC_FAIL` ทุกวินาที (สมมติฐาน: ไม่มีเวลาใน RTC → หาตำแหน่งแรกช้า)
- **Play Services ไม่ได้สิทธิ์ตำแหน่งหลังอัปเดตทับ** → `pm grant com.google.android.gms ACCESS_FINE_LOCATION/ACCESS_COARSE_LOCATION` แก้แล้ว · ต้องทำซ้ำทุกครั้งที่ลง GMS ใหม่
- คำนวณเส้นทางช้า: เพราะยังไม่มีตำแหน่งปัจจุบัน (เน็ต ping 48ms ปกติ)
- ลูกศรทิศหมุนไปมา: จอมีแต่ `UNCALI_MAG` + ROTATION_VECTOR ของ MTK (ไม่มี magnetometer ปรับเทียบ) · Maps ใช้เข็มทิศตอนจอด/ช้า, Waze ใช้ทิศ GPS · ปิดเฉพาะแอพไม่ได้บน Android 9
