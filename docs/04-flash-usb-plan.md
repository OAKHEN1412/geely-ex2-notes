# 04 — แผนเตรียม USB flash + ปัญหาที่เจอ

## เป้าหมาย

เตรียมแฟลชไดรฟ์ที่มีแพตช์โครงสร้างถูกต้อง เพื่อเสียบเข้ารถแล้วรันปลดล็อก (ดู docs/01)

## ปัญหาที่เจอ: USB ตัวที่ต่ออยู่เขียนไม่ได้

- ไดรฟ์ D: ที่ต่อไว้เป็น **แฟลชไดรฟ์ Windows 11 ของแท้จาก Microsoft** (`KDI-MSFT Windows 11`, KDI = Kingston Digital)
- ระดับดิสก์ตั้ง **`IsReadOnly = True` (write-protect ระดับเฟิร์มแวร์)** — ไม่ใช่แอตทริบิวต์ที่สั่งเคลียร์ง่าย ๆ
- `Format-Volume` ล้มเหลว: `Cannot perform the requested operation when the drive is read only`
- เซสชันไม่ได้รันแบบ Administrator ด้วย

**สรุป: ไม่ฝืนใช้ตัวนี้** — เอาแฟลชไดรฟ์ Windows ของแท้ไปเสี่ยงเพื่อวางแพตช์ ~100MB ไม่คุ้ม และได้ไดรฟ์พฤติกรรมเดาไม่ได้มาใช้กับงานที่พลาดแล้วจอพัง

## ทางเลือก (เรียงจากแนะนำ)

1. **แฟลชไดรฟ์อันอื่น** — อันไหนก็ได้ ≤32GB สะดวกสุด (Windows ฟอร์แมต FAT32 ตรง ๆ)
2. **USB card reader + SD/microSD** — ตัวอ่านการ์ดแบบดองเกิล USB แสดงตัวเป็น USB mass storage เหมือนกัน รถมองเห็นไม่ต่าง (ต้องเป็นตัวอ่านเสียบ USB ไม่ใช่ช่องในตัวโน้ตบุ๊ก)
3. **External HDD/SSD** ที่ฟอร์แมต FAT32 ได้ (เกิน 32GB ใช้ fat32format GUI) — แผนสำรอง บางหัวรถจ่ายไฟไม่พอ
4. **ดันทุรังปลดล็อก Kingston อันเดิม** — เปิด PowerShell as Admin → `diskpart` → `select disk 1` → `attributes disk clear readonly` (สื่อ retail มักไม่ติด/เด้งกลับ) — ไม่แนะนำ

## เมื่อได้ USB แล้ว: ใช้สคริปต์

```powershell
# ต้องโหลด ZIP แพตช์จาก Google Drive มาก่อน (ดู docs/01)
.\tools\prep-usb.ps1 -Drive E -Zip "C:\path\to\patch.zip" -Format
```

สคริปต์จะ:
- ปฏิเสธถ้าไม่ใช่ removable / ถ้าดิสก์ read-only
- ฟอร์แมต FAT32 (ถ้าใส่ `-Format`)
- แตก ZIP ลงราก USB
- **ตรวจย้อน** ว่าได้ `3C6025_*_user_995\OS\update.zip` ถูกต้อง และ `update.zip` ยังไม่ถูกแตก
- อ่านบิลด์จากชื่อโฟลเดอร์มาเตือนให้เช็กกับจอรถ
