# 01 — ปลดล็อก ADB บนจอ Geely EX2

## ปลดล็อกนี้ทำอะไรจริง ๆ

1. จอเป็น **Android ที่ root มาจากโรงงาน** — แพตช์ไม่ได้เพิ่ม/ถอนสิทธิ์ระบบ สิ่งที่ถูกปิดคือ "ประตูเข้า" ไม่ใช่ตัวสิทธิ์
2. แพตช์เข้าทาง **ช่องอัปเดตปกติ** — ไฟล์ `update.zip` บน USB ถูกอ่านโดยตัวอัปเดตของรถเอง จอรีบูตเข้า Recovery แล้วรันสคริปต์
3. ผลลัพธ์เดียวคือ **ADB ถูกเปิด** — หลังรีบูต จอยอมรับ ADB over Wi-Fi + มีปุ่มเปิด/ปิดใน Dialer Mode
4. จากนั้น **ลงแอปจากคอมได้เลย** ผ่าน ADB ในวง Wi-Fi เดียวกัน
5. **ย้อนกลับได้** ด้วย Factory Reset (ลบแอปที่ลงเพิ่ม + ปิด ADB)

> ความเสี่ยง: ทำผิดลำดับ/ผิดเวอร์ชัน อาจทำให้ระบบไม่เสถียร ฟังก์ชันบางอย่างหยุด หรือหนักสุดต้องลงซอฟต์แวร์จอใหม่ทั้งชุด

## 0. ตรวจความเข้ากันได้ (สำคัญที่สุด)

ใช้ได้เฉพาะจอที่ตรงทุกบรรทัด:

| รายการ | ค่า |
|--------|-----|
| หน่วยจอ | **IHU629G** (Beidou Intelligent Connected Vehicle Technology) |
| Model | **EEBADF1** |
| ซอฟต์แวร์ | **Flyme Auto E 1.8.0** |
| Build | **1111 หรือ 1114** เท่านั้น |

ดูที่: **ตั้งค่ารถ (Vehicle Settings) → ล่างสุด → รถของฉัน (My Car)**
ถ้าไม่ตรง — หยุด ห้ามรันแพตช์

## 1. เตรียม USB FAT32 + แพตช์

- USB **FAT32** (≤32GB ฟอร์แมตจาก Windows ได้ตรง ๆ, ใหญ่กว่านั้นใช้ [fat32format GUI](https://ridgecrop.co.uk/index.htm?guiformat.htm))
- โหลดแพตช์ตามบิลด์ (Google Drive):
  - บิลด์ 1111: `https://drive.google.com/file/d/1rvTfF4WoTgXcZ98_y73fKRayZVBgxaOZ/view` → โฟลเดอร์ `3C6025_SW0E22H0128H111100000_user_995`
  - บิลด์ 1114: `https://drive.google.com/file/d/1RF5ut5r_zVGCxfe2O3LKc3SrecRVp3td/view` → โฟลเดอร์ `3C6025_SW0E22H0306H111400000_user_995`
- แตก ZIP วางทั้งโฟลเดอร์ที่ **รากของ USB** โครงสร้างต้องเป็น:

```
USB (ROOT)
└── 3C6025_..._user_995
    └── OS
        └── update.zip   ← ห้ามแตกไฟล์นี้
```

> จุดพลาดบ่อย: แตก `update.zip` ออกมา หรือวางโฟลเดอร์ซ้อนอีกชั้น → รถมองไม่เห็นอัปเดต
> ใช้ [tools/prep-usb.ps1](../tools/prep-usb.ps1) จัดโครงสร้าง + ตรวจให้อัตโนมัติ

## 2. เปิดเมนูวิศวกร

1. เสียบ USB รอจอขึ้นว่าตรวจพบอุปกรณ์ USB
2. **ปิด Bluetooth** (ไม่งั้นแอปโทรศัพท์จะโทรออกจริง)
3. เปิดแอป **โทรศัพท์ (Phone)** บนจอ
4. กดรหัส **Engineering Mode** (ดูสูตรด้านล่าง)

## 3. รันแพตช์

1. ในเมนูวิศวกร กดไอคอนติดตั้งอัปเดต (ตัวที่ทำเครื่องหมายสีเขียว)
2. จอ **รีบูตเข้า Recovery แล้วรันเอง** ไม่ต้องกดอะไรเพิ่ม
3. ตอนจบ **ขึ้น error** — ตั้งใจให้เป็นแบบนั้น ไม่ใช่ความผิดพลาด
4. กดค้างปุ่ม **Previous Track** บนพวงมาลัย จนจอรีสตาร์ตอีกรอบ
5. → ถึงตรงนี้ **ADB เปิดแล้ว** ถอด USB ได้

## 4. ต่อ Wi-Fi + จด IP

1. เข้าเมนูซ่อน → เลือกรายการทำเครื่องหมายสีน้ำเงิน → ตั้งค่า Wi-Fi ของจอ
2. ต่อจอเข้า Wi-Fi บ้าน / hotspot มือถือ — **คอมต้องอยู่วงเดียวกัน**
3. จด **IP address** ที่คอลัมน์ซ้าย

## 5. เปิดสวิตช์ ADB

1. เปิดแอปโทรศัพท์ กดรหัส **Dialer Mode**
2. กดปุ่ม **ADB** หนึ่งครั้ง

> ทำซ้ำทุกครั้งที่จะลงแอปใหม่: เปิด Wi-Fi → จด IP → Dialer Mode → กด ADB (ไม่ต้องรันแพตช์อีก)

## 6. ลงแอปด้วย ADB AppControl

1. โหลด [ADB AppControl](https://adbappcontrol.com/en/#download)
2. ใส่ IP ของจอในช่องขวาบน → กด **WiFi**
3. ครั้งแรกยอมรับติดตั้ง **ACBridge**
4. **Install → Quick Install** → เลือก `Geely-Ex2-Car.apk`

## รหัสเข้าเมนูซ่อน

| โหมด | สูตร | ใช้ทำอะไร |
|------|------|-----------|
| Engineering Mode | `#*(เดือน+10)(วันที่)(ชั่วโมง)` | เมนูวิศวกร — รันแพตช์ + ตั้งค่า Wi-Fi |
| Dialer Mode | `#*(เดือน+5)(วันที่)(ชั่วโมง)` | หน้าที่มีปุ่ม ADB |

- วันที่ = 2 หลัก
- ชั่วโมง = **ระบบ 12 ชั่วโมง, 2 หลักเสมอ** (19 นาฬิกา → `07`)
- ตัวอย่าง 20/07 เวลา 19:xx → Engineering `#*172007`, Dialer `#*122007`

## คืนค่าเดิม

**ตั้งค่ารถ → รถของฉัน → คืนค่าจากโรงงาน (Factory Reset)** → แอปที่ลงเพิ่มถูกลบ + ADB ปิดกลับ
