# ตารางแปล UI — Geely EX2 Remote (VN -> ไทย -> อังกฤษ)

ข้อความ UI ทุกคำสกัดจากไฟล์แอปจริง แล้วแปลเป็นไทย/อังกฤษ  
คอลัมน์ **Tiếng Việt** = ข้อความต้นฉบับที่ต้องแทนที่ตอน patch

> ห้ามแปลชื่อ VHAL/protocol: `WINDOW_POS`, `DOOR_POS`, `GEAR_SELECTION`, `EV_BATTERY_LEVEL`, `AVAS`, `47800`, UUID

**รวม 125 รายการ**

## แท็บ / นำทาง

| Tiếng Việt | ไทย | English |
|---|---|---|
| Tổng quan | ภาพรวม | Overview |
